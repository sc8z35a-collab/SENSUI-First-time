# バグ監査レポート — ABYSSAL DESCENT

検証方法: 全ソース (約 8,100 行) 精読 + ヘッドレス再現スクリプト `node tools/test/bugprobe.mjs` + Playwright によるスクリーンショット確認 (844×390, 横画面モバイル)。

区分: **[再現]** = スクリプト/描画で実際に再現 / **[画面]** = スクリーンショットで確認 / **[コード]** = コード上で論理的に確定

## A. シミュレーション・ゲームロジック

1. **[再現] ピッチ安定化 (SAS) の符号が逆** — `sim/sub.js _mix` / `autopilot.js`。艦首上げ (pitch>0) に対し垂直スラスターが更に艦首上げトルク (+408) を出す。SAS は常時不安定化方向に働き、有無で減衰が変わらない。
2. **[再現] 配電盤を遮断しても電気火災が消えない** — `systems.js`。成長 0.02×O2/21 > 減衰 0.012 のため、遮断 60 秒後も強度 0.5→0.97 に増加。
3. **[再現] 貫通部 P2 を隔離→開放すると OFF だった暖房ブレーカーが勝手に投入される** — `systems.js isolate` が元の状態を記憶しない。
4. **[再現] 隔離中の貫通部に繋がるブレーカーを「トリップ→リセット」経路で投入できる** — `toggleBreaker` と DC「ブレーカー復帰」が隔離チェックを通らない。
5. **[再現] 煙・低体温・過圧での死亡が「二酸化炭素中毒」と表示される** — `systems.js` 死因判定が hypoxia/hypercapnia の 2 択。
6. **[再現] 混濁流中にセーブ→ロードすると強海流 (0.45 m/s) が永久に止まらない** — `env.turbidityT` が保存されず `currentExtra` だけ復元。カードも自動解決しない。
7. **[再現] バッテリー「セル不均衡・熱暴走の恐れ」障害に実害が無い** — 1 時間放置で温度は 5.8 °C まで下がるだけ。
8. **[再現] オフラインのバッテリーは温度が更新されず、熱暴走遮断時の 90 °C のまま永久に冷えない** — `_drain` の早期 return。
9. **[再現] NAV 画面 (HDG-UP) の回転方向が逆** — `mfd.js drawNAV toScr`。yaw=0.7 で前方 10 m の点が (-9.85,-1.70) に描画 (正: 0,-10)。北向き以外では POI・航跡・母船が全て誤った方位に出る。
10. **[再現] 「スラスターを切り離す」と再接続手段が消える** — カードが解決済みになり、他に再接続 UI が無いため永久に使用不能。
11. **[再現] NAV 電源喪失で AP が自動解除されても VBT 指令がラッチされ続ける** — `autopilot.js update` が `engage(false)` を通らず `_apVbt` 後始末なし。30 秒後も `vbtCmd=-0.86`。
12. **[コード] セーブ時に `env.quake` も保存されず、地震中のロードで地震カードが永久に残る。**
13. **[コード] スラスターの `_preThermal` が保存されず、熱保護停止中にセーブ→ロードで軸受劣化が治る。**
14. **[コード] 航行中にセーブ→「続きから」で AP を解除していても `navTo()` により強制再接続・「自動航行開始」メッセージ再表示** (`game.js load`)。
15. **[コード] AP 解除後も `nav.on` が残る** — NAV パネルに「航行中/残距離」が表示され続け、再接続で旧目的地へ無言で航行再開。
16. **[コード] 修理手順失敗時 (再起動失敗・ポンプ再起動失敗等) も成功チャイムが鳴る** — `onRepairDone` が常に 'good'。
17. **[コード] 深度計ドリフト障害の `silent: true` が未参照** — 「気付きにくいはず」の故障が即座に警告音・バナーで通知される。
18. **[コード] 熱暴走で自動遮断したバッテリーを SYS パネルから即座に再接続できる** (インターロック無し)。
19. **[コード] コンソール ALT ボタンは常に 8 m、SPD は常に 0.8 m/s を設定** — タブレット側 (現在高度を使用) と挙動不一致、設定値を上書き。
20. **[コード] コンソール LT1/LT2 は LIGHT ブレーカー状態を無視して照明レベルを変更** (HUD 照明ボタンは拒否)。
21. **[コード] 緊急浮上: NAV 無電源時に「自動操縦不可」警告が 2 回、ウェイト 0 個でも「ウェイト 0 個投棄」と表示。**
22. **[コード] 照明の減光 (brownout) がバッテリー A のみで判定** — A 切離し+クロスタイで B (100%) 給電中でも照明が常に 60%。
23. **[コード] 生物はスポーン瞬間に「発見」扱い** — 25〜55 m 先の暗闇で見えていなくても図鑑登録 (`life.js _sight`)。
24. **[コード] 母船 (全長 92 m・喫水 7 m) にコライダーが無く船体をすり抜ける。**
25. **[再現] SPEC.V0 のコメント「VBT 150 L で中性」は誤り** — 実際は VBT 0 L で中性 (水深 10 m で +3 kg)。
26. **[画面] 潜航開始直後に浮力 -273 kg** — 水面の部分浮上モデルで、操作前から沈み始める (スクショ f2)。
27. **[コード] 火災箇所 (NAV/SONAR/CABIN/HEAT) に関係なく火花・煙が常に右下バスバーから出る。**
28. **[コード] `props.js mats()` の並行呼び出し競合** — 難破船と母船のビルドで共有マテリアルを二重生成。

## B. 表示・UI

29. **[画面] 負のゼロ表示** — HUD 速力「-0.0」、浮力「-0」/「+0」が点滅、PFD 速度「-0.00」。
30. **[コード] PFD 深度テープが水面付近で「-10」「-20」の負深度目盛を描く。**
31. **[画面] 開始 4 秒でハダカイワシが図鑑登録済** (#23 の実例, スクショ p5)。
32. **[画面] 指定フォント (Rajdhani / Share Tech Mono / Noto Sans JP) を一切読み込んでいない** — @font-face もリンクも無く、端末依存フォールバックで描画。
33. **[コード] HUD 照明ボタンの ON 表示が主照明のみで判定** — 投光器のみ点灯中は OFF 表示。
34. **[画面] AP パネルの HDG 目標が未接続時 0° のまま** (現在方位 090 と不一致)。
35. **[画面] 緊急呼吸器ボタンが未使用なのに「0 min」表示** — `emergencyO2` は初回装着時にしか 1.5 h にならない。
36. **[再現] アナログ計器の目盛数字が重複** — O2 流量計「0,1,1,2,2」、艦内気圧計「0,1,1,2,2,3,3」(`Math.round`)。
37. **[コード] O2 手動バイパス供給中も O2 流量計が 0 を指す。**
38. **[コード] コンソール CAM ボタン (レーザー切替) の LED がカメラ電源を表示し、押しても変化しない。**
39. **[コード] NAV 画面: 距離 R〜1.5R の POI が外周リングの外 (ヘッダー上) に描画** — 範囲外矢印の閾値が 1.5R。
40. **[コード] SYS 画面のバッテリー % 文字色が '#001' 固定** — 残量が少ないと暗い背景上で読めない。
41. **[コード] `sys.flash` がどこからも設定されない** — 「低電圧時の MFD ちらつき」機能が死んでいる。
42. **[コード] 見回しを離すと毎秒 25% で視線が正面へ戻る** — 頭上ブレーカー等を見て離してタップすると狙いがずれる。「◎ 視点を正面に戻す」ボタンとも矛盾。
43. **[コード] 浸水水面のロール補正が無効** — `rotation.set(-π/2-pitch, 0, roll)` の XYZ 順ではロールが円盤法線回りになる。
44. **[コード] 煙パーティクル用 `smokeMat` (NormalBlending) が未使用** — 暗色 (0.07) の煙が加算合成で描かれほぼ不可視。
45. **[コード] 「続きから」直後に投棄済みウェイト/マニピュレーターの落下アニメが再生される。**

## C. 描画・性能・音響・その他

46. **[コード] 熱水噴出孔 PointLight×3・ランダーのストロボが接近時に追加 + POI の visible 切替でライト数が変わり、全マテリアルが再コンパイル** (exterior.js で回避済みの問題が再発しカクつく)。
47. **[コード] `setMaxAnisotropy` がキャッシュ内のテクスチャにしか効かない** — clone されたテクスチャ (コックピットのほぼ全て) と canvasTexture (固定 8) に画質設定が反映されない。
48. **[コード] 魚 1 匹ごとに毎フレーム Vector3×6・Matrix4 を new** (最大約 500 匹) — モバイルで GC スパイク。
49. **[コード] 落下したウェイト・アーム等を scene から外すだけで dispose しない** (GPU メモリリーク)。
50. **[画面] `THREE.Clock` は r186 で非推奨** — 起動毎にコンソール警告。
51. **[コード] 効果音 'extinguish' 'vent' と play 経由の 'ping' が定義のみで未使用** — 消火器使用が無音。
52. **[コード] ノイズバッファ (brown 5 s) が非ループのため 'rumble' (8.2 s)・'implode' (7.5 s) が途中で切れる。**
53. **[コード] 軋み音 (creak) の遅延ショットで周波数スイープが `now` 起点** — 後発音はスイープ終盤しか聞こえない。
54. **[コード] `tools/dev/setup.sh` は `ldconfig` の無い環境で毎回 `sudo playwright install-deps` を実行。**
55. **[コード] リポジトリに `tools/dev/__pycache__/*.pyc` がコミット済** (.gitignore 漏れ)。
56. **[コード] 未使用コード**: `alarmsAck`, `vbtPumpOK_power`, `moles`, `uShake`, `linDepth`, `releaseBallast()`, `onLook`, インシデントの `auto` フラグ, `maxMeshes`, `allMeshed`, shots.py の `INIT`。
